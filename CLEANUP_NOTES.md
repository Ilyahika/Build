# Viva Beta V1 — очистка и доставка базы

- Удалены неиспользуемые SVG emoji, исходные промпты генерации картинок, вспомогательные манифесты, тестовые сценарии и служебные описания ассетов.
- Сохранены все 20 atlas webp с рыбами, fish_atlas.png и lure_atlas.png, поскольку они участвуют в отрисовке.
- Файлы JavaScript/CSS разных версий оставлены, потому что index.html подгружает их одновременно.
- База данных, если она была в исходном архиве, не очищается и не изменяется.
- Кнопка «Скачать базу» теперь отправляет SQLite-файл личным сообщением бота на ADMIN_ID из config.py. Для доставки администратор должен предварительно написать боту /start.
- Запрос отправки — POST с серверной проверкой Telegram initData и прав администратора. При ошибке показывается сообщение вместо ложного успеха.
- Команда /backup в личном чате остаётся доступной.
