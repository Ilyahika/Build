# Viva Beta V1 — final visual bundle

Распакуйте содержимое папки Viva в проект сервера. Файлы v11–v20 — подключённые модули интерфейса, а не резервные версии. Они необходимы для работы.

Перед заменой файлов отдельно сохраните текущую SQLite базу данных и .env (в архиве их нет).

Обновлено: плавная анимация кейсов с рандомной точкой остановки внутри выигрышной карточки (12–88% ширины), единый дизайн коллекции кейсов, обновлённые карточки рулетки и стиль кнопок без горчичного жёлтого.

Тесты: проверка синтаксиса и целостности архива. Реальные Telegram платежи и производительность в WebView нужно проверить отдельно.
