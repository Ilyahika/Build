# Viva Fishing 3.0 — Telegram Mini App

Готовая версия **на базе рабочего Viva Admin Live 2.0**: рыбалка, снасти, рюкзак, 20 рыб, находки, 4 кейса и действующая админ-панель. Код Python и JavaScript работает с одним сервером Render; GitHub Pages не требуется.

## Как обновить существующий Render

1. **Не удаляй рабочий проект!** Сохрани копию репозитория/предыдущий коммит на случай отката.
2. Распакуй архив. **Перенеси содержимое папки** `viva_fishing_release/` **в корень** своего GitHub-репозитория. Не загружай ZIP как отдельный файл и не оставляй файлы в дополнительной вложенной папке.
3. **Добавь два новых файла обязательно**: `fishing.py` и `fishing_ui.js`. Остальные файлы замени новыми. Токен бота в код не вставляй.
4. Сохрани изменения через **Commit changes**.
5. В Render: **Manual Deploy → Deploy latest commit**, если Auto-Deploy не начал обновление автоматически.
6. Переменные `BOT_TOKEN`, `ADMIN_ID` и адрес сервиса оставь как в работающей версии (админ фиксирован как `1181838335` на сервере). Команды Render **не меняются**:

   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn main:app --host 0.0.0.0 --port $PORT --workers 1`

7. Дождись статуса **Live**, проверь `https://ТВОЙ-СЕРВИС.onrender.com/health` и `/health/db` (`database: connected`, `tables_ready: true`). Закрой Mini App в Telegram и заново открой кнопку `/start → Открыть`.

**Примечание о базе:** `db.py` **создаёт только отсутствующие таблицы**, поэтому при подключении к прежней сохранённой SQLite3 существующие игроки и балансы остаются на месте. **Однако на бесплатном Render диск временный**, поэтому новая публикация может сбросить старую SQLite3 независимо от кода; для реальных игроков нужен постоянный диск или внешняя БД. `database.db` не нужно добавлять в публичный GitHub.

**Редкости рыб:** `Обычная`, `Редкая`, `Эпическая`, `Морская`, `Секретная`.

**Находки:** коряга, ракушка, старая монета, жемчужина, якорь, реликвия, золотой компас и золотая корона. Редкость **`Эксклюзив` выделена золотым цветом**.

**12 видов снаряжения:** 6 удочек и 6 оснасток (`Обычная`, `Редкая`, `Эпическая`, `Морская`, `Секретная`, `Эксклюзив`). Начальные удочка и поплавок выдаются автоматически. После экипировки снастей растёт шанс редких уловов и находок.

**4 кейса со снастями** открываются бесплатно за пойманную рыбу, без покупки, ставок и реальных платежей. Новое открытие появляется каждые:
- 3 улова: береговой кейс;
- 8 уловов: озёрный кейс;
- 18 уловов: морской кейс;
- 35 уловов: тайный кейс.

В интерфейсе показаны возможные награды и точные шансы на каждую. Каждый кейс гарантированно выдаёт снасть, предмет сохраняется в рюкзаке.

**Рюкзак:** количество рыб, список рыб с возможностью продажи за виртуальные монеты (по одной категории или всех сразу), находки, снасти с экипировкой. Удалена заглушка «Техработы» из рюкзака; глобальные технические работы и управление ими по-прежнему работают только через админ-панель.

**Админ-панель** (ID `1181838335`) сохранила управление игроками, балансами, блокировками, онлайн-статистикой и техработами. В её сводку добавлены пойманные рыбы, предметы в инвентарях и открытые кейсы. В карточке игрока теперь виден его прогресс рыбалки.

## API и структура

- `GET /api/fishing/state` — состояние рыбалки, каталог и рюкзак.
- `POST /api/fishing/cast` — бесплатный заброс, тело `{"location":"pond"}`. Доступные location: `pond`, `lake`, `sea`, `ocean`, `stream`.
- `POST /api/fishing/equip` — экипировка снасти, тело `{"gear_key":"starter_rod"}`.
- `POST /api/fishing/case/open` — бесплатный кейс, тело `{"case_key":"shore"}`.
- `POST /api/fishing/sell` — продажа рыбы, тело `{"fish_key":"all"}` или ID вида рыбы.

Все маршруты требуют проверенную подпись Telegram Mini App. Изменения инвентаря и баланса выполняются на сервере с транзакциями SQLite3. Пользователь не может изменять баланс через JavaScript. Между забросами обычного игрока перерыв 4 секунды.

## Файлы

- `main.py` — FastAPI + aiogram, подключение `fishing.router` и выдача статических файлов.
- `fishing.py` — логика уловов, находок, экипировки, кейсов и SQLite3 API.
- `fishing_ui.js` — рыбалка, снасти и рюкзак.
- `app.js`, `index.html`, `style.css` — основная оболочка и оформление.
- `db.py` — новые таблицы рыбалки с сохранением старых.
- `admin.py`, `admin.js` — показатели рыбалки в админке.
- Остальные модули сохранены из рабочей версии.

**Не публикуй `BOT_TOKEN`, `.env` или персональные данные игроков в репозитории.**
