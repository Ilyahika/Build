# Viva Fishing 4.1

Telegram Mini App: сине-золотой интерфейс в стиле исходной Viva, исходная анимированная загрузка, рыбалка с вываживанием и серверным учётом прогресса.

## Запуск

Python 3.11+.

```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1
```

Переменные окружения:

- `BOT_TOKEN` — токен бота из BotFather.
- `WEBAPP_URL` — публичный HTTPS-адрес приложения. На Render используется `RENDER_EXTERNAL_URL`.
- `DB_PATH` — путь к базе, например `/var/data/database.db`.

В Render команда старта: `python -m uvicorn main:app --host 0.0.0.0 --port $PORT --workers 1`.
Администратор: Telegram ID `1181838335`, меняется в `config.py`. Клиентские поля не дают права администратора: каждый запрос проверяет подпись Telegram на сервере.

## Обновление и сохранение

1. Перед обновлением сделайте копию текущей SQLite командой `python backup_db.py /путь/к/backup.db` на действующем сервере, с его `DB_PATH`. Утилита копирует согласованную базу, включая WAL.
2. Замените код. **Не удаляйте существующую базу.** В архиве новой базы нет. Запуск автоматически добавляет недостающие таблицы и поля; старые идентификаторы рыб и снастей сохранены.
3. Для Render подключите постоянный диск с mount path `/var/data` и задайте `DB_PATH=/var/data/database.db`. Если старая база находилась в папке проекта, до переключения скопируйте её через SQLite backup на постоянный диск, иначе новая папка будет означать новую базу.
4. Перезапустите сервер и проверьте `/health/db`, затем профиль в Telegram.

Все игровые изменения записываются сразу, транзакционно. Включены WAL и `synchronous=FULL`. Баланс, опыт, инвентарь, кейсы, блокировки, журнал и состояние заброса находятся в SQLite. Штатный перезапуск сохраняет их при сохранности файла базы. Отключённый сервер не обслуживает игру. Без постоянного диска Render может удалить локальную базу при пересоздании или развёртывании сервиса; код этого предотвратить не может. Резервные копии нужно хранить также отдельно от диска сервера.

## Игровые правила

- Один заброс каждые 180 секунд для всех, включая администратора. Таймер начинается с заброса, сорвавшаяся рыба его не отменяет.
- Локации: пруд — 1 уровень, озеро — 5, море — 10, океан — 18, секретный ручей — 25. Меняются стрелками или свайпом по воде.
- Рыба движется по шкале. Ползунок перемещает светлую зону; удерживайте рыбу внутри. Вес и редкость увеличивают скорость и сужают зону; снасти облегчают управление. Длительность — 12–18 секунд, сервер считает результат. Подделать итоговое количество опыта одним запросом нельзя.
- Рыба выдаётся один раз при победе. Дубликаты запроса завершения не дают повторную награду. При обрыве связи повторно откройте приложение: незавершённый заброс восстановится, но время поединка продолжает идти. Просроченный заброс считается неудачным.
- Вес сохраняется в истории уловов, личный рекорд показан в профиле. Продажа идёт по цене вида рыбы за штуку.
- EXP за улов: `25 + 20 × индекс редкости + целая часть(вес × 2)`. За открытие кейса — 35. Для следующего уровня нужно 100, 150, 200… EXP.
- Семь редкостей: 🖤 Обычный, 💙 Редкий, 🩵 Улучшенный, 💜 Эпический, 💛 Легендарный, ❤️ Мифический, 🤍 Абсолютный.
- Шесть удочек из списка пользователя; катушки, лески, приманки, колебалки и вертушки имеют редкости. Леска и приманки не расходуются. Эффект экипировки фиксируется при начале поединка.
- Бесплатен только стартовый комплект. Остальные снасти выпадают из кейсов. Прямая покупка оснастки отключена также на сервере. Платежей настоящими деньгами и вывода нет.
- В магазине кейс покупается и открывается за одну операцию. Возможные награды и вероятности показаны до покупки. Кейсы, выданные администратором, отображаются в магазине и открываются бесплатно перед покупными. Дубликаты снастей хранятся по количеству. В рюкзаке только рыба и находки; снаряжение выбирается на главном экране через шесть слотов.
- Прежние бесплатные открытия за число уловов отменены, история открытых кейсов сохранена.

## Администратор

Игроки загружаются страницами, есть поиск по имени, нику и ID. Подробный профиль и инвентарь открываются только по кнопке «Открыть». Можно выдавать и забирать монеты, EXP, снасти, рыбу, находки и кейсы (положительное / отрицательное количество), блокировать с причиной, сбрасывать таймер, включать техработы. Вернулись сводка и диагностика с глубокой проверкой, распределение уровней, онлайн с автообновлением, фильтры и сортировки, подробная карточка игрока, точная установка монет и EXP, сбросы, личные сообщения от бота, рассылка с прогрессом, журнал и экран техработ. Все изменения записаны в журнал. Нулевые остатки не показываются. Уровень пересчитывается из EXP, включая понижение после изъятия опыта.

Дома, машины, доход от домов и прежние игровые API отключены. Старые таблицы оставлены для совместимости и сохранения данных.

## Где менять баланс

Цены, доступность, состав и веса выпадения кейсов меняются в админке → «Кейсы». Вес 0 отключает снасть; шанс считается как вес предмета / сумма весов × 100%. Нельзя сохранить пустой пул. Настройки хранятся в SQLite, сохраняются после перезапуска, применяются к новым открытиям и к публичным шансам. Базовые каталоги и параметры: `fishing.py`: `FISH`, `GEAR`, `CASES`. Список рыб взят из исходного архива (20 видов), цены и параметры новых снастей — стартовый баланс для дальнейшей настройки.

## Проверка

`python -m unittest discover -s tests -v` (требует дополнительно `pip install httpx`). Проверяются серверный поединок, защита от повторной выдачи, таймер, уровни, запрет прямой покупки снастей, экипировка, настройка и открытие кейсов, продажи, полная админка и сохранение при повторной инициализации базы. Запуск на реальном аккаунте и визуальная проверка внутри Telegram выполняются после развёртывания.

## Дизайн 4.1

Вернулись исходные анимированная заставка с поплавком, волнами и логотипом Viva, сцены берегов и сине-золотая палитра. Полная админка использует общий с игрой дизайн. Уведомления плавно спускаются сверху, имеют таймер скрытия и подсветку по редкости награды или по типу события. Кнопки получили свечение, блик и отклик на нажатие.
