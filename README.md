# Viva Admin Live 2.0 — Render

Готовая версия Viva, собранная на основе работающего `viva_render_fixed.zip`. Сохранены Telegram-бот (aiogram), FastAPI, игровые профили, SQLite3, существующее управление игроками и интерфейс. Добавлена панель управления в строгой чёрно-бело-жёлто-красной палитре и режим техработ.

## Как установить

1. Перед обновлением на GitHub сохрани рабочий коммит (или скачай резервную копию репозитория). **Не удаляй действующую базу данных.**
2. Распакуй архив и загрузи **все файлы** в корень того же GitHub-репозитория, к которому подключён Render. В том числе обязательно **новый файл `system_state.py`**. Подтверди **Commit changes**.
3. В Render открой Web Service → **Manual Deploy → Deploy latest commit** (если Auto-Deploy не сработал).
4. Проверь Render → Environment: `BOT_TOKEN` — **новый действующий** токен Telegram-бота. `ADMIN_ID` в `config.py` задан как **1181838335** и больше не зависит от Environment.
5. Build Command: `pip install -r requirements.txt`.
6. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT --workers 1`.
7. Когда Render станет `Live`, открой бота, отправь `/start`, нажми **«Открыть»**. Для администратора появится вкладка **«Админ»**, далее **«Техработы»**.
8. Проверь `https://ТВОЙ-СЕРВЕР.onrender.com/health` и `/health/db`: сервер и таблицы должны быть доступны.

## Что добавлено

- **Админ ID 1181838335**: авторизация исключительно по проверенной сервером подписи `Telegram.WebApp.initData`, остальные пользователи не могут управлять панелью.
- **Сводка**: число игроков, активные сейчас / 15 минут / 24 часа, новые за сутки, заблокированные, виртуальные монеты и звёзды, число игр, побед, тапов, машин, уровней домов.
- **Онлайн**: список пользователей, которые отправляли серверу подписанные запросы за последние 75 секунд. Mini App запрашивает системный статус примерно раз в 10 секунд (когда открыт). Сводка и список онлайн в админке обновляются каждые 12 секунд. Это **оценка активности**, а не постоянное вебсокет-соединение.
- **Игроки**: поиск, фильтры, подробная карточка, выдача/списание виртуальных денег и звёзд, установка баланса, изменение уровня дома, блокировка/разблокировка, подарки и другие существующие инструменты.
- **Техработы**: включение, выключение, изменение текста сообщения, запись в журнал. Для всех обычных игроков — полноэкранная заглушка; игровые API блокируются сервером (`503 MAINTENANCE`). Администратор **не блокируется** и продолжает пользоваться приложением. После выключения экраны сами обновятся на следующем опросе.
- **Журнал**: включение и выключение техработ, операции с игроками.

## Изменённые файлы

- `main.py` — новый `/api/system/status` и heartbeat.
- `auth.py` — запрет игровых запросов при техработах с исключением для администратора.
- `system_state.py` — новый модуль хранения состояния техработ в SQLite3.
- `db.py` — автоматически создаётся таблица `site_settings`. Существующие таблицы и игровые данные сохраняются.
- `admin.py` — статус/переключатель техработ, список онлайн, расширенная статистика.
- `admin.js`, `app.js`, `style.css`, `index.html` — интерфейс, автообновление, полноэкранное сообщение.
- `config.py` — фиксированный ADMIN_ID и новая версия.

## Важные ограничения

- На **бесплатном Render локальная SQLite3 не является постоянным хранилищем**. После нового развёртывания, сна или пересоздания экземпляра данные игроков и состояние техработ могут сбрасываться. Для настоящей игры и надёжного режима обслуживания нужен Render Persistent Disk (платно) с `DB_PATH=/var/data/database.db` или внешняя постоянная база данных. Этот архив **не решает проблему постоянного хранения на Free**.
- Статус техработ обновляется на открытом Mini App примерно раз в 10 секунд при наличии связи. Без интернета или при спящем сервере мгновенное обновление невозможно. Сервер всегда проверяет режим при каждом игровом запросе.
- При изменении файлов сервера требуется повторный deploy Render; при одновременном запуске старого и нового процесса на одном токене Telegram возможен временный `TelegramConflictError`.
- Не загружай `.env`, токен, `database.db` и резервные копии базы в публичный GitHub.

## Проверено локально

- FastAPI с синтетическими **подписанными** Telegram `initData`: права администратора, вход игрока, `/api/system/status`, `GET /api/admin/live`, включение и выключение техработ, блокировка серверных игровых действий, работа администратора во время техработ, операции с балансом и блокировками, ник, журнал.
- Синтаксис Python (`compileall`) и JavaScript (`node --check`).
- В Chromium с тестовыми ответами API: сводка, онлайн, настройки техработ и полноэкранная заглушка.

Фактическую работу конкретного Render и живого Telegram необходимо проверить после развёртывания.
